# همراه‌یاب | HamrahYab

سامانه اندرویدی فارسی برای **امنیت و همراهی خانواده، مراقبت از سالمندان و پیدا کردن گوشی گم‌شده**.

- بازار اولیه: ایران
- انتشار هدف: کافه‌بازار و مایکت
- توسعه‌دهنده: Maliar Software Group
- شناسه بسته پیشنهادی: `ir.maliarpro.hamrahyab`
- وضعیت فعلی مخزن: مرحله مستندسازی محصول و آماده‌سازی اسکلت فنی؛ هنوز اپلیکیشن قابل انتشار یا Backend عملیاتی در این مخزن تأیید نشده است.

## سه کاربرد محصول

1. **خانواده:** اشتراک‌گذاری دوطرفه و رضایت‌مندانه موقعیت، درخواست موقعیت و مکان امن.
2. **مراقبت سالمندان:** SOS، محدوده امن و مشاهده آخرین وضعیت دستگاه.
3. **گوشی گم‌شده:** مشاهده آخرین موقعیت ثبت‌شده و درخواست موقعیت تازه در صورت روشن و متصل بودن دستگاه.

## اصول غیرقابل‌مذاکره

- رضایت صریح صاحب دستگاه و تأیید دوطرفه ارتباط.
- امکان توقف اشتراک‌گذاری و لغو دسترسی.
- عدم ردیابی مخفیانه.
- نمایش زمان و دقت هر موقعیت؛ داده قدیمی به‌عنوان موقعیت زنده نمایش داده نمی‌شود.
- عدم ادعای مکان‌یابی گوشی خاموش یا بدون امکان ارسال داده.
- SOS پایه و کنترل‌های حریم خصوصی پشت اشتراک پولی قرار نمی‌گیرند.

## فناوری هدف

Kotlin، Jetpack Compose، MVVM، Room، WorkManager، Fused Location Provider با abstraction، Kotlin Ktor و PostgreSQL. جزئیات در نقشه راه فنی آمده است.

## وضعیت توسعه

این مخزن در حال حاضر شامل تصمیم‌های محصول و برنامه اجرایی است. پیاده‌سازی کد Android و Backend باید در مراحل بعدی انجام و با build و تست واقعی تأیید شود.
