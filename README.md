# همراه‌یاب | HamrahYab

اپلیکیشن اندرویدی فارسی برای **همراهی امن خانواده، مراقبت رضایت‌مندانه از سالمندان و پیدا کردن دستگاه‌های متعلق به خود کاربر**.

- بازار هدف: ایران
- انتشار هدف: کافه‌بازار و مایکت
- توسعه‌دهنده: Maliar Software Group
- شناسه بسته: `ir.maliarpro.hamrahyab`

## کاربردهای اصلی

1. **خانواده:** اتصال دوطرفه، درخواست موقعیت با رضایت صاحب دستگاه و مشاهده آخرین موقعیت مجاز.
2. **مراقبت از سالمندان:** مسیر توسعه SOS، مکان امن و مراقبت شفاف با کنترل در اختیار صاحب دستگاه.
3. **گوشی گم‌شده:** مشاهده آخرین موقعیت ثبت‌شده دستگاه‌های خود کاربر؛ مکان‌یابی دستگاه خاموش یا بدون ارتباط شبکه تضمین نمی‌شود.

## وضعیت فنی

- برنامه Android با Kotlin و Jetpack Compose و لایه‌های اولیه دامنه/ذخیره‌سازی محلی در مخزن موجود است.
- اسکیمای اولیه Cloudflare D1 و قرارداد API در `backend/cloudflare` و `docs/BACKEND_API_CONTRACT.md` ثبت شده‌اند.
- Worker در حال توسعه است؛ مسیرهای سلامت، نشست احراز‌شده، صندوق درخواست، پاسخ به درخواست، ارسال موقعیت و دریافت آخرین موقعیت در مرحله MVP پیاده‌سازی/آزمون هستند.
- **هنوز هیچ Worker یا پایگاه D1 در Cloudflare مستقر نشده و ارتباط واقعی بین دو گوشی فعال نیست.** احراز هویت/ثبت‌نام و صدور نشست، ایجاد و مدیریت دعوت/اتصال و مدیریت رضایت باید پیش از استفاده عملیاتی تکمیل شوند.
- بیلد CI و تست‌های Worker باید برای هر commit جداگانه بررسی شوند؛ موفقیت یک مرحله به معنی آماده بودن محصول برای انتشار نیست.

## اصول حریم خصوصی و ایمنی

- رضایت صریح صاحب دستگاه و تأیید دوطرفه ارتباط.
- درخواست موقعیت روی دستگاه مقصد قابل مشاهده و قابل رد است.
- امکان لغو رضایت و قطع ارتباط باید همیشه در اختیار صاحب داده باشد.
- عدم ردیابی مخفیانه و عدم دور زدن مجوزهای Android.
- نمایش زمان ثبت، دقت و منبع هر موقعیت؛ موقعیت قدیمی به‌عنوان زنده نمایش داده نمی‌شود.
- عدم ادعای مکان‌یابی گوشی خاموش، بدون اینترنت یا فاقد امکان ارسال داده.
- SOS پایه و کنترل‌های حریم خصوصی پشت اشتراک پولی قرار نمی‌گیرند.

## فناوری هدف

Kotlin، Jetpack Compose، Room، WorkManager و لایه مستقل مکان‌یابی در Android؛ Cloudflare Workers + D1 به‌عنوان گزینه اولیه بک‌اند آزمایشی با حفظ امکان مهاجرت. انتخاب سرویس OTP/SMS و Push برای ایران منوط به آزمون عملی است.
